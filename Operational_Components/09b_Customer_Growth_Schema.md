# Customer Growth Database Schema

## 1. Objective

To define the database schemas required for the Autonomous Customer Acquisition and Growth engine. This includes storing customer profiles and detailed marketing performance metrics. This schema will be housed in a dedicated `Customer_Growth.db` SQLite database.

## 2. Schema Definition (SQL)

### `customer_personas`

Stores the detailed persona definitions generated by the `MarketSegmentAgent` for each SaaS product.

```sql
CREATE TABLE customer_personas (
    persona_id INTEGER PRIMARY KEY AUTOINCREMENT,
    saas_id INTEGER NOT NULL,
    name TEXT NOT NULL, -- e.g., "Solo Podcaster", "Indie Game Dev"
    persona_details_json TEXT NOT NULL, -- JSON blob with demographics, pain points, goals, online habitats
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (saas_id) REFERENCES saas_products (saas_id)
);
```

### `marketing_campaigns`

Stores high-level information about each marketing campaign.

```sql
CREATE TABLE marketing_campaigns (
    campaign_id INTEGER PRIMARY KEY AUTOINCREMENT,
    saas_id INTEGER NOT NULL,
    name TEXT NOT NULL, -- e.g., "Q4 Growth Campaign for SaaS-A"
    status TEXT NOT NULL CHECK(status IN ('design', 'live', 'paused', 'completed')) DEFAULT 'design',
    total_budget_usd REAL NOT NULL,
    start_date DATETIME,
    end_date DATETIME,
    FOREIGN KEY (saas_id) REFERENCES saas_products (saas_id)
);
```

### `channel_performance`

A time-series table to log the performance and spend for each channel within a campaign.

```sql
CREATE TABLE channel_performance (
    metric_id INTEGER PRIMARY KEY AUTOINCREMENT,
    campaign_id INTEGER NOT NULL,
    channel TEXT NOT NULL, -- e.g., 'google_ads', 'reddit_ads', 'seo_content'
    timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
    spend_usd REAL NOT NULL, -- Spend in the last 24 hours
    impressions INTEGER NOT NULL,
    clicks INTEGER NOT NULL,
    conversions INTEGER NOT NULL, -- e.g., sign-ups
    cac REAL, -- Calculated Customer Acquisition Cost for the channel
    FOREIGN KEY (campaign_id) REFERENCES marketing_campaigns (campaign_id)
);

CREATE INDEX idx_channel_performance_campaign_time ON channel_performance (campaign_id, timestamp DESC);
```

### `customers`

Stores information about individual users who have signed up for a SaaS product.

```sql
CREATE TABLE customers (
    customer_id INTEGER PRIMARY KEY AUTOINCREMENT,
    saas_id INTEGER NOT NULL,
    persona_id INTEGER, -- The persona this customer most closely matches
    email TEXT UNIQUE,
    status TEXT NOT NULL CHECK(status IN ('trial', 'active', 'churned', 'at_risk')) DEFAULT 'trial',
    ltv REAL DEFAULT 0.0, -- Lifetime Value, updated over time
    churn_probability REAL, -- Updated by the ChurnPredictionAgent
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (saas_id) REFERENCES saas_products (saas_id),
    FOREIGN KEY (persona_id) REFERENCES customer_personas (persona_id)
);
```
