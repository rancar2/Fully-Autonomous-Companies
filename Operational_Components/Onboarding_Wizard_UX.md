## 2. Onboarding Wizard UX (Meta SaaS Builder)

This document outlines the user experience (UX) for the onboarding wizard of the meta-SaaS builder. The goal is to guide the user—the "investor"—through the process of launching their first autonomous SaaS company.

---

### Steps:

1.  **Welcome & Mindset Primer**
    *   The first screen sets the expectation: “This platform builds and runs SaaS tools for you. You are the investor, not the builder.” This helps frame the user's role as a decision-maker rather than a hands-on creator.

2.  **Input Selector**
    *   The user provides the initial seed for the SaaS idea by selecting from a series of options:
        *   **Keyword:** A high-level concept or industry (e.g., "fitness," "writing," "project management").
        *   **Dataset:** An optional dataset that can be used to inform the SaaS product.
        *   **Business Persona:** The target audience for the SaaS (e.g., "students," "small businesses," "content creators").
        *   **Monetization Type:** The preferred business model (e.g., "subscription," "pay-per-use," "freemium").

3.  **First SaaS Pitch**
    *   The platform's agents perform a live generation of the SaaS idea, including a name, tagline, and core value proposition, based on the user's input.

4.  **Customize Stack**
    *   The user can toggle key features on or off, such as:
        *   Authentication (Auth)
        *   Webhooks
        *   Stripe Integration
        *   And other common SaaS features.

5.  **Preview UX**
    *   A live preview of the application's user interface is generated using TurboFrames. The user can make minor tweaks to the copy, branding, and UI elements.

6.  **Agent Launch**
    *   With a final click of the "Start Company" button, all agent loops are initiated, and the user is taken to a dashboard where they can monitor the roadmap and progress of their new autonomous business.

---

🧠 **Learning Loop:** Every onboarding session provides valuable data that trains the internal models on real founder-level expectations and preferences, helping to improve the quality of autonomously generated SaaS products over time.
